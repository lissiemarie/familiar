# Familiar

A 2D atmospheric puzzle-adventure about a witch's cat familiar exploring the surrounding home of its missing owner.

# Project Status

Pre-production

#Project Goals

-Design and develop an original 2D game.
-Build reusable gameplay systems using C# and Unity.
-Create original hand-drawn artwork and animation.
-Compose and implement original music and audio.
-Document the complete game-development process.

# Development

Familiar is in the design and technical planning phase. Game systems, visual development, UI/UX, audio, and implementation will be documented as this project progresses. 🐈‍⬛
